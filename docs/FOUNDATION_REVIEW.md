## OTR

Revision `370c39d9771c606eb36484354817bec98e8b311d`. Read README.md, app.js (corpus and rendering), index.html and styles.css architecture.

OTR is a dependency-free static experience. `MODULES` selects illustrative records by keywords; `DAY` drives a chronological reveal; `PROFILE` accumulates interpretations. `em`/`inf`/`rel` separate emitted, inferred and relational records. The playback/feed and cumulative reveal are useful product concepts for M3. Adapt that plain language and progressive disclosure to Compose.

Do not reuse the corpus as a tracker database. Its README explicitly says it is illustrative, not an audit of named companies; volumes are plausible estimates. Records have no per-observation provenance. Noma must replace all illustrative counts with measured events and distinguish measured activity from dataset classifications. Relational records are an explanatory concept, not a measurable signal in M0. Do not copy web DOM rendering or keyword-based activity guesses.

## SketchGPT

Revision `fff5d91cc9ce7748b40801a76f8240a08d18e9e5`. Read README.md, docs/mobile-models.md, web/browser.html model selection/loading, web/work.mjs grounding and retrieval, web/sw.js offline architecture.

Reuse ideas, not the browser runtime: explicit model downloads, pinned weights, separate download/memory budgets, context-window ladders, conservative memory headroom, cancellation and source-visible answers. `work.mjs` documents why quoted evidence does not guarantee supported conclusions. Noma must compute all counts and ownership outside the model and validate any eventual narrative against permitted evidence.

Replace WebGPU/WebLLM, browser cache, service worker and Ollama with an evaluated Android-native runtime at M2. Browser load-time memory estimates cannot establish Android inference safety; the mobile study explicitly leaves real-device throughput and steady-state memory unverified. Do not carry over fixed RAM-to-model tiers or chatbot UI. M0 has no model, prompts or model downloads.

## Destination and next steps

Kotlin + Compose; Android 10/API 29 minimum. First verify official Android API limits, then document architecture, privacy and threats before implementation. A DNS request is evidence of a requested name, not proof of a successful connection or personal-data transfer. Temporal overlap with app activity must never become app ownership. Unknown attribution is a valid result.

No code or dataset is copied from either foundation; reuse is conceptual. Check licenses before any future source or asset reuse.
